# Slate

> Excel帳票を、壊れないAI入力フォームへ。

Slateは既存のExcel帳票を原本のまま保ち、人とAIには入力可能な値だけを扱わせるローカルファーストの試作です。

## Prototype

依存関係はありません。`index.html` をブラウザで開くと、工事見積書を題材にしたフォームUIを確認できます。

```text
Excelテンプレート（固定）
        ↕ template-map.json
values.md ← フォーム / AI
        ↕
完成Excel（別名保存）
```

この試作ではフォーム入力、金額の自動計算、AIが読むためのMarkdownプレビュー／ダウンロードを実装しています。実際の `.xlsx` の読込・書戻しは次の段階です。

## 安全原則

- Excelの書式、結合セル、数式、印刷設定、外部リンクは変更しない。
- `template-map.json` の許可された入力項目だけを書き込む。
- 金額・小計・税・合計は数式結果として扱い、直接入力させない。
- 元ファイルは常に残し、出力は別名保存する。
